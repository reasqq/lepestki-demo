# Лепестки · демонстрация обновления магазина

Адаптивный кликабельный прототип по 57 предоставленным PNG-макетам.

Каталог → карточка букета → корзина → тестовые бонусы → оформление → заказ в личном кабинете. В кабинете доступны профиль, адреса, история заказов и баланс. Все данные вымышленные. OpenCart, Bonus Plus, оплата и отправка заказов не подключены.

## Демонстрация за 4 минуты

1. Откройте «Тихое счастье», добавьте в корзину и увеличьте количество.
2. Введите 500 тестовых бонусов и примените. При включённой упаковке: 2 × 5 900 + 300 − 500 = 11 600 ₽.
3. Перейдите в кабинет и откройте существующий заказ. Вернитесь в корзину.
4. Перейдите к оформлению, проверьте ошибки пустой формы. Нажмите «Заполнить тестовыми данными», подтвердите их использование.
5. Покажите отказ оплаты, затем успешную имитацию. Откройте новый заказ и баланс.

Настройки тестовых бонусов доступны в кабинете. Для повторного показа используйте «Сбросить демонстрацию» в подвале. Корзина и данные хранятся только в браузере посетителя.

## Локальный запуск

Нужен Node.js, установка зависимостей не требуется:

```sh
node server.cjs
```

Откройте http://127.0.0.1:4173. Проверка расчётов: `node tests.cjs`.

## Материалы и границы

[Группировка 57 экранов, карта сценариев, требования и вопросы](docs/MATERIALS.md). [Галерея экранов](screenshots/index.html).

Баланс 1 250, курс 1:1 и лимит 50% показаны в макетах, но не подтверждают фактические настройки Bonus Plus. Доступные 1 000, ожидающие 250, исключение доставки из базы списания, округление вниз и фиксация списания при создании локального заказа — условные демонстрационные решения. Начисление, сроки, уровни, регистрационные подарки и акции не моделируются. Упаковка +400 ₽/шт., курьер 300 ₽ и самовывоз 0 ₽ также условные.

Перед внедрением нужны тестовая копия магазина, версия OpenCart и темы, список модификаторов и сторонних модулей, документация API Bonus Plus и схема обработки заказов. Нужно согласовать базу расчёта, исключения, скидки, момент списания/начисления, отмены, возвраты и повторы. Прототип не является готовым внедрением.
